# M10-009 — Portfolio Release Governance & Multi-Community Production Certification

Status: IN_PROGRESS

## Purpose

Take the M10-008 factory-produced community candidates and certify them as a governed multi-community portfolio without collapsing community isolation, release authority, lineage, or rollback boundaries.

## Frozen boundary

M10-009 owns portfolio candidate registration, cross-community isolation checks, release-set composition, portfolio-level certification evidence, coordinated approval state, partial-failure handling, rollback eligibility, and production-release readiness adjudication.

M10-009 does not automatically publish communities, does not bypass per-community release authority, does not merge community data/configuration namespaces, does not permit one community's PASS to conceal another community's FAIL, and does not mutate accepted production baselines.

## Required implementation

- register factory-produced candidates in a deterministic portfolio manifest;
- preserve exact per-community candidate/package fingerprints;
- prove profile/config/evidence namespace isolation across communities;
- certify every community independently before portfolio readiness can pass;
- fail the portfolio if any member is failed, unresolved, stale, or authority-blocked;
- preserve per-community rollback eligibility and lineage;
- model coordinated approval without allowing one approval to authorize another community;
- generate immutable portfolio certification evidence;
- prove partial portfolio failure remains visible and cannot be averaged away;
- produce a portfolio release-readiness artifact without publishing.

## Acceptance boundary

M10-009 may be accepted only when multiple factory-produced community candidates can be registered and certified together while preserving exact community isolation, any individual failure forces portfolio NO-GO, release authority remains community-scoped, rollback lineage is complete, no publishing occurs, accepted evidence remains immutable, and inherited certification gates pass.
