# M4-001 — Render Persistence Completion

Status: ACCEPTED

Established immutable-history-oriented render persistence downstream of canonical semantic reports. `reporting.render_versions` anchors each presentation artifact to one `report_id` and render type, records presentation-input identity, render/template/renderer versions, artifact integrity/storage metadata, lifecycle/QA state, and supersession lineage. `reporting.render_dependencies` preserves exact presentation dependency lineage and supports reverse impact lookup.

The persistence layer intentionally does not implement version allocation, render-contract policy, media/diagram binding, rendering adapters, publication pointers, or publication authority; those remain isolated to later Milestone 4 tickets.

Acceptance evidence: 273 repository tests passed and repository validation PASS.
