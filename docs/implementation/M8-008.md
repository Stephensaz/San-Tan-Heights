# M8-008 — Seller Report Experience

Status: IN_PROGRESS

## Purpose

Build the Seller-facing governed report experience from the canonical SELLER report payload without exposing Agent-only technical lineage or creating new intelligence.

## Behavior

- Requires `metadata.report_variant == SELLER`.
- Preserves upstream section order, card order, finding IDs, seller-friendly labels, display text, status, confidence, limitations, disclaimers, and freshness timestamps.
- Omits per-finding source snapshot IDs and semantic fingerprints from the Seller view model.
- Rejects broken section/card/finding references.
- Produces an immutable deterministic view fingerprint.
- Does not recalculate scores, value, confidence, publication scope, or property meaning.
