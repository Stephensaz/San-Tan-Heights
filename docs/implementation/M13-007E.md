# M13-007E — Prior-State Delta & Material-Change Engine

Status: IMPLEMENTED — AWAITING ACCEPTANCE

## Purpose

Compare the exact prior certified seller-intelligence state with the newly certified current D state and produce a deterministic, immutable change ledger.

## Change states

E supports exactly:

- NEW
- CHANGED
- UNCHANGED
- STALE
- RESOLVED
- NO_LONGER_APPLICABLE
- UNKNOWN

## Governed significance

Change detection and significance classification are separate. Every delta requires an explicit versioned significance rule keyed to the intelligence dimension and detected change state. No implicit weights, utility functions, or hidden scores are allowed.

Allowed significance classes are INFORMATIONAL, NOTICEABLE_CHANGE, MATERIAL_CHANGE, REVIEW_REQUIRED, and INSUFFICIENT_INFORMATION.

## Boundary

E preserves the exact prior/current state fingerprints, temporal boundaries, values, unknown transitions, and per-delta fingerprints. It does not convert significance into strategy, recommendation, seller score, action generation, prediction, ranking, or M12 execution.

## Acceptance

E passes only if prior/current identity and temporal order are enforced, every frozen change state is executable, significance requires explicit governed rules, unknown transitions remain explicit, replay is deterministic, state artifacts remain immutable, inherited regressions pass, and zero waivers/open defects remain.
