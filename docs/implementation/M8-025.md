# M8-025 — Stable Property Routing

Status: IN_PROGRESS

## Purpose

Provide deterministic, version-independent presentation routes over the canonical property identity without embedding mutable address text, report versions, presentation hashes, or access-control decisions in the route.

## Behavior

- Loads a locked property-routing registry.
- Requires canonical lowercase UUID property identity.
- Builds explicit Agent, Seller, and Public audience routes from the same immutable property ID.
- Resolves only canonical paths and rejects unknown audience segments, query/fragment payloads, and noncanonical identities.
- Keeps routes independent from report version, presentation fingerprint, address text, findings, and market data.
- Treats routing as identity only; authorization remains the responsibility of the governed delivery/access layer.
- Produces deterministic route fingerprints.
- Does not create property identity, infer aliases, redirect between audiences, or broaden publication eligibility.
