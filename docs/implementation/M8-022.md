# M8-022 — Public PDF

Status: IN_PROGRESS

## Purpose

Compose the governed PUBLIC report into a deterministic Public PDF document model using the accepted M8-019 PDF foundation while preserving the minimal PUBLIC-only presentation surface.

## Behavior

- Consumes only the accepted `PublicReportView`.
- Preserves Public-approved property identity, freshness, summary, canonical section/card/finding order, confidence wording, limitations, and disclaimers.
- Uses the locked M8-019 US Letter template plan.
- Omits Agent/Seller-only lineage, private report metadata, source snapshot IDs, semantic fingerprints, report snapshot ID, and dependency-manifest hash by construction.
- Produces a deterministic Public PDF document fingerprint.
- Does not recover hidden lineage, broaden publication scope, rewrite evidence, infer missing facts, or create PDF-specific property facts.
- Byte-level PDF rendering remains delegated to the certified renderer integration; this ticket establishes the Public PDF composition contract on the frozen governed Public projection.
