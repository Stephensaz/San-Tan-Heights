# M8-032 — Golden Presentation Fixture Set

Status: IN_PROGRESS

## Purpose

Freeze a deterministic, synthetic-only presentation truth set and independent expected outcomes that exercise the complete Milestone 8 presentation architecture before M8-033 integration certification.

- PRIVACY_ADVERSARIAL

## Required scenario coverage

The frozen set includes representative cases for standard interior, limited evidence, uncertainty, conflict, stale data, corner/cul-de-sac/common-area/road adjacency, no-photo media, analytical detail, historical reports, many changes, empty states, responsive layouts, long-report pagination, privacy-adversarial inputs, and accessibility.

## Governance

- Fixtures are synthetic only.
- Real homeowner, APN, parcel, MLS, listing, client, or production property data are prohibited.
- Reserved synthetic property IDs and Example/Test/Sample addresses are required.
- Agent, Seller, and Public expectations are defined independently from the truth fixture file.
- Web, PDF, and print expectations are mandatory.
- Topology, pagination, accessibility, freshness, empty-state, and privacy expectations are explicit where applicable.
- The fixture loader fails closed on missing categories, missing audience expectations, missing surface expectations, privacy violations, or non-synthetic identities.
- Fixture and fixture-set fingerprints are deterministic.

## Relationship to adjacent tickets

- M8-031 supplies the visual regression harness that consumes certified baselines and structural assertions.
- M8-032 supplies the frozen synthetic truth/expected-outcome package that M8-033 will execute against.
- M8-032 does not execute M8-033 certification and does not add new presentation capabilities.
