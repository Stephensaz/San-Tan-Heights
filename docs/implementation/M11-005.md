## Statement typing and lineage

Every communication statement is explicitly typed as one of:

- `FACT`
- `HYPOTHETICAL`
- `MONITORING_GUIDANCE`
- `LIMITATION`
- `QUALIFIER`

Each emitted statement carries deterministic lineage fingerprints.

Hypothetical scenario content remains explicitly labeled hypothetical and is never presented as current fact.

## Preserved constraints

The communication layer preserves:

- current eligible buyer-alternative counts;
- competitive-pressure state and material qualifier;
- strategy-dimension states;
- missing/suppressed limitations;
- M11-003 hypothetical labeling;
- M11-004 human-review monitoring guidance;
- source/evidence lineage.

It does not strengthen or invent facts.

## Output boundary

Communication output:

- is never PUBLIC;
- cannot recommend a list price;
- cannot predict a sale price;
- cannot guarantee proceeds or outcomes;
- cannot infer seller motivation, acceptance, buyer behavior, or protected-class information;
- cannot approve, publish, schedule, or execute an external action;
- always has `external_action_capability: NONE`.
