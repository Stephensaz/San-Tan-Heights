# M8-002 — Design Token System

Status: IN_PROGRESS

## Purpose

Define a deterministic semantic token registry for the consumer presentation layer.

This layer owns neutral visual primitives only. It does not decide audience content, property meaning, template certification, or agent branding policy.

## Token groups

- colors — semantic surface/text/border/accent roles
- spacing — layout rhythm in pixels
- radius — corner radius primitives
- typography — type-size primitives
- layout — shared content-width and gutter primitives

## Guardrails

- Registry identity/version/status are locked.
- Registry loads fail closed on malformed or non-positive values.
- Color tokens use six-digit uppercase hex values.
- Runtime views are immutable.
- Registry fingerprint is deterministic through canonical serialization.
- Audience-specific behavior belongs to M8-006.
- Branding overrides belong to M8-026.
