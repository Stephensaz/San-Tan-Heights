# M8-018 — Mobile Navigation & Progressive Disclosure

Status: ACCEPTED

## Purpose

Provide mobile navigation and progressive disclosure over the accepted COMPACT responsive layout without changing canonical order, audience eligibility, or property meaning.

## Behavior

- Consumes an accepted `ResponsiveLayoutPlan` in `COMPACT` mode only.
- Preserves every semantic section in canonical order.
- Keeps every section reachable whether expanded or collapsed.
- Tracks active section separately from expanded/collapsed state.
- Toggling changes disclosure state only; it never removes, reorders, or reclassifies content.
- Activation does not force expansion or create a different semantic hierarchy.
- Rejects unknown active/expanded/toggle targets.
- Produces a deterministic navigation-state fingerprint.
- Does not hide governed content, infer importance, alter audience scope, or create mobile-specific property facts.
