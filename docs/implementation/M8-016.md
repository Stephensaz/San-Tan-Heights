# M8-016 — Confidence / Limitation Components

Status: IN_PROGRESS

## Purpose

Render already-approved confidence and limitation wording as audience-appropriate presentation components without converting, scoring, translating, or inventing confidence language.

## Behavior

- Consumes only the accepted M8-015 `EvidenceDisclosureSet`.
- Uses the locked M8-006 confidence visibility policy: Agent `DETAILED`, Seller `FRIENDLY`, Public `SELECTIVE`.
- Preserves confidence and limitation wording exactly as supplied upstream.
- Omits a component when both confidence and limitation are absent rather than inventing placeholder text.
- Rejects audience/disclosure mismatches and blank optional wording.
- Produces a deterministic component-set fingerprint.
- Does not calculate confidence, map confidence to numeric scores, infer risk, or create new property interpretation.
