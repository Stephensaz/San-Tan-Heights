# M1-010 — Event Runtime

Status: ACCEPTED

Implemented a fail-closed event runtime that loads the event registry, validates producer authorization, reason codes and JSON payload schemas, calculates deterministic payload hashes, persists immutable orchestration events, and writes transactional outbox entries using the caller's database transaction.

## Key files
- `src/kernel/events/*`
- `schemas/events/event-envelope.schema.json`
- `schemas/events/event-payload.schema.json`
- `registries/events/events.yaml`
- `tests/unit/test_event_runtime.py`
- `tests/contract/test_event_schema_contract.py`

## Acceptance
- Unknown events fail closed.
- Unauthorized producers fail closed.
- Unknown reason codes fail closed.
- Payload hashes are deterministic.
- Event persistence and outbox enqueue use the same caller cursor/transaction.
