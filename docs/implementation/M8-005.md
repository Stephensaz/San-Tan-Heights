# M8-005 — Friendly Label Runtime

Status: IN_PROGRESS

## Purpose

Expose the already-governed M3 friendly-label registry to the presentation layer without creating a second label source or inventing fallback wording.

## Guardrails

- Uses `STH-FRIENDLY-LABELS-v1.0` as the single source of truth.
- Resolves labels by explicit Agent, Seller, or Public audience.
- Unknown terms fail closed.
- Missing audience labels fail closed; no cross-audience fallback is permitted.
- Resolution preserves caller order for deterministic composition.
- The runtime changes labels only; it does not change findings, evidence, confidence, eligibility, or meaning.
