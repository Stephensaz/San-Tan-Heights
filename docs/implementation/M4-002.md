# M4-002 — Render Version Counters

Status: ACCEPTED

Added a concurrency-safe `reporting.render_version_counters` table keyed by immutable `report_id + render_type`, plus `RenderVersionAllocator`. Allocation uses `SELECT ... FOR UPDATE`; `MAX(render_version)+1` is prohibited. WEB, PDF, PRINT, and MOBILE_PREVIEW counters advance independently.

Acceptance evidence: focused allocator/persistence tests passed; full repository suite passed.
