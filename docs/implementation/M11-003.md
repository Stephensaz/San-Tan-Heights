# M11-003 — Seller Scenario & Strategy Sensitivity Engine

Status: ACCEPTED

## Purpose

Take certified M11-002 property-level seller strategy and evaluate controlled what-if scenarios that help a human understand how the strategy context changes when governed assumptions or market conditions change.

## Accepted scenario surface

M11-003 can model hypothetical changes to:

- competitive pressure;
- buyer depth;
- verified differentiation;
- new-construction pressure;
- pricing-response environment;
- week-over-week direction;
- Day-7 review-trigger state;
- Day-10 review-trigger state;
- Day-14 review-trigger state.

- `registries/seller_intelligence/m11-003-seller-scenario-sensitivity-v1.0.yaml`
- `src/seller_intelligence/scenario.py`
- `tests/unit/seller_intelligence/test_scenario.py`
- `certification-evidence/m11-003/seller-scenario-sensitivity-acceptance-v1.0.json`

## Baseline versus hypothetical separation

M11-003 maintains two distinct provenance channels:

- **baseline lineage** — certified M11-002/M11-001 evidence and strategy fingerprints;
- **hypothetical lineage** — scenario assumption fingerprints only.

The two lineage sets must remain disjoint.

A hypothetical assumption cannot be represented as a certified fact.

## Sensitivity classifications

Each modeled target is classified as:

- `CHANGED` — hypothetical state differs from certified baseline;
- `UNCHANGED` — hypothetical state equals certified baseline;
- `HYPOTHETICAL_ONLY` — the baseline state is unavailable or missing.

Targets not included in a scenario remain explicitly unmodeled.

## Output boundary

Every scenario is explicitly labeled hypothetical and remains:

- SELLER-only;
- `public_eligible: false`;
- `external_action_capability: NONE`.

The scenario DTO contains no fields for recommended list price, predicted sale price, guaranteed proceeds, guaranteed outcomes, seller-acceptance prediction, buyer-behavior prediction, seller motivation, or automatic action.
