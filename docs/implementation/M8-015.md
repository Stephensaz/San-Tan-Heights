# M8-015 — Evidence Disclosure Components

Status: ACCEPTED

## Purpose

Project already-governed evidence into audience-appropriate disclosure components without reconstructing hidden lineage or creating new property meaning.

## Behavior

- Consumes only the typed Agent, Seller, or Public report view produced by the accepted audience experience layer.
- Uses the locked M8-006 audience presentation policy for evidence depth: Agent `DETAILED`, Seller `STANDARD`, Public `LIGHT`.
- Preserves canonical section/card/finding order, finding label, status, confidence label, limitation, and report disclaimers.
- Exposes `source_snapshot_id` and `semantic_fingerprint` only for the Agent view.
- Seller and Public disclosures fail closed if Agent-only lineage fields are present.
- Rejects audience/view mismatches.
- Produces a deterministic disclosure-set fingerprint.
- Does not query raw findings, infer sources, reconstruct hidden evidence, broaden audience eligibility, or reinterpret property facts.
