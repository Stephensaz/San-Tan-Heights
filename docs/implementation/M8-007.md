# M8-007 — Agent Report Experience

Status: IN_PROGRESS

## Purpose

Build the Agent-facing governed report experience from the canonical AGENT report payload without creating new intelligence or changing upstream policy.

## Behavior

- Requires `metadata.report_variant == AGENT`.
- Preserves upstream section order, card order, finding IDs, display text, confidence labels, limitations, and freshness timestamps.
- Exposes agent-detail fields without inventing values.
- Rejects broken section/card/finding references.
- Produces an immutable deterministic view fingerprint.
- Does not recalculate scores, value, confidence, publication scope, or property meaning.
