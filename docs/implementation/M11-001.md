# M11-001 — Seller Opportunity Intelligence Layer

Status: ACCEPTED

## Purpose

Consume only certified community baselines and governed findings to produce seller-focused opportunity signals without modifying core platform semantics.

## Accepted capability

M11-001 implements the first frozen Seller Intelligence capability:

1. **Current Buyer Alternative Set**
2. **Competitive Pressure**

The implementation is contained in:

- `registries/seller_intelligence/m11-001-seller-opportunity-v1.0.yaml`
- `src/seller_intelligence/opportunity.py`
- `tests/unit/seller_intelligence/test_opportunity.py`
- `certification-evidence/m11-001/seller-opportunity-acceptance-v1.0.json`

## Input governance

The layer:

- requires certified community-baseline inputs;
- accepts only governed alternative types;
- suppresses stale evidence;
- suppresses non-SELLER-tier evidence;
- suppresses QA-failed evidence;
- fails closed on uncertified-baseline evidence;
- preserves evidence fingerprints as lineage.

## Output governance

The output is deterministic and contains:

- the governed Current Buyer Alternative Set;
- a relative Competitive Pressure signal;
- explicit evidence lineage;
- SELLER output tier;
- `public_eligible: false`;
- `external_action_capability: NONE`.

Competitive Pressure is explicitly qualified as a relative signal only. It is not a valuation, list-price recommendation, sale-price prediction, or outcome guarantee.
