# M11-001 — Seller Opportunity Intelligence Layer

Status: IN_PROGRESS

## Purpose

Consume only certified community baselines and governed findings to produce seller-focused opportunity signals without modifying core platform semantics.

## First implementation capability

M11-001 begins with:

1. Current Buyer Alternative Set
2. Competitive Pressure

## Frozen boundaries

M11-001:

- consumes governed certified inputs only;
- suppresses stale, non-SELLER-tier, and QA-failed inputs;
- fails closed on uncertified baseline inputs;
- produces explainable deterministic seller opportunity signals;
- preserves source/evidence lineage;
- defaults to SELLER-only output.

M11-001 does not:

- modify M1–M10 core platform behavior;
- infer unsupported seller behavior;
- determine value;
- recommend a list price;
- predict a sale price;
- guarantee an outcome;
- infer protected-class information;
- expose seller strategy publicly by default;
- perform autonomous external actions or publication.

## Acceptance target

The first M11-001 implementation is acceptable only when buyer-alternative construction and competitive-pressure classification are deterministic, stale/ineligible evidence is suppressed, uncertified inputs fail closed, lineage is preserved, public eligibility remains false, external action capability remains NONE, and inherited M8/M9/M10 certification gates remain green.
