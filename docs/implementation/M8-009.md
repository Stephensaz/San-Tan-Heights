# M8-009 — Public Report Experience

Status: IN_PROGRESS

## Purpose

Build the Public-facing governed report experience from the canonical PUBLIC report payload while exposing only public-safe presentation fields and never broadening publication eligibility.

## Behavior

- Requires `metadata.report_variant == PUBLIC`.
- Preserves upstream section order, card order, finding IDs, public-friendly labels, display text, status, selectively exposed confidence, limitations, disclaimers, and freshness timestamps.
- Omits source snapshot IDs, semantic fingerprints, dependency-manifest hashes, and other internal lineage from the Public view model.
- Rejects broken section/card/finding references.
- Produces an immutable deterministic view fingerprint.
- Does not infer, reclassify, recalculate, or broaden any governed finding or publication scope.
