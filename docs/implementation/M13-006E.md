Acceptance requires exact B/C/D lineage, explicit assumptions for modeled dimensions, certified reference facts, deterministic numeric and categorical comparisons, descriptive-only scarcity context, uncertainty/limitation carry-forward, deterministic replay, full inherited regressions, zero waivers, and zero open defects.
