# M13-007C — Seller-Relevance & Applicability Engine

Status: IMPLEMENTED — AWAITING ACCEPTANCE

## Purpose

Consume a certified M13-007B governed input bundle and determine, using explicit reproducible rules, whether a certified intelligence dimension is applicable to the subject property and why.

## Boundary

C may produce only APPLICABLE, NOT_APPLICABLE, UNKNOWN, or BLOCKED decisions with explicit rule ids, reasons, preserved source dependency fingerprints, exclusions, unknowns, and limitations.

C does not assemble the unified seller-intelligence state, score relevance, apply hidden weighting, recommend actions, predict outcomes, rank scenarios, score sellers, or execute M12 actions.

## Acceptance

C passes only when property-specific rule evaluation is deterministic; B lineage is preserved; exclusions and unknowns remain explicit; non-ready B bundles fail closed; decision-set replay is exact; forbidden scoring/decision fields are absent; inherited regressions pass; and zero waivers/open defects remain.
