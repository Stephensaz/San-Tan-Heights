# M13-006I — Seller/Agent Scenario Eligibility & Presentation Contracts

Status: IN_PROGRESS

## Purpose

Consume certified M13-006H scenario/comparison explanations and determine exactly what may be exposed to Agent and Seller surfaces, how eligible content may be simplified, which disclosures/limitations/unknowns must remain attached, which content must be suppressed, and whether screen/export use is eligible.

## Governing rule

Presentation may reduce complexity but may never increase certainty.

## Boundary

M13-006I owns eligibility, visibility, deterministic simplification, mandatory disclosure inheritance, suppression reason codes, semantic-equivalence checks, screen/export eligibility, and physical Agent/Seller payload separation.

M13-006I does not render reports, materialize presentation artifacts, manage scenario sessions, create recommendations, rank scenarios, select winners, predict outcomes, execute listing actions, or publish externally.

## Seller isolation

Seller contracts are built independently from seller-eligible source fields. The implementation may not create an unrestricted Agent/master payload and hide fields afterward.

Unknowns, limitations, material assumptions, and mandatory disclosures survive Seller simplification.

## Acceptance

Acceptance requires exact H lineage, separate Agent/Seller contracts, deterministic simplification, mandatory qualifier preservation, explicit suppression, screen/export separation, semantic neutrality, deterministic replay, inherited regressions, zero waivers, and zero open defects.
