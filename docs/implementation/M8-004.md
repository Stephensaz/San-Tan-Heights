# M8-004 — Report Layout Shell

Status: IN_PROGRESS

## Purpose

Provide the deterministic report-section shell consumed by Agent, Seller, and Public experiences.

## Canonical section order

1. Property Header
2. Summary
3. Property DNA
4. Lot & Location
5. Home Characteristics
6. Market / Buyer Context
7. Evidence
8. Changes
9. Freshness
10. Glossary / Disclosures

## Guardrails

- Sections may be omitted when unavailable or ineligible.
- Missing sections are never synthesized.
- Duplicate section keys are rejected.
- Manual reordering is rejected.
- The shell contains presentation structure only; governed content remains upstream.
