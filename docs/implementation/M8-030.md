# M8-030 — Empty / Missing / Unavailable States

Status: ACCEPTED

## Purpose

Present governed absence states clearly without converting missing data into negative property facts, inventing causes, or exposing private diagnostics to Seller/Public audiences.

## Input contract

- Consumes only typed governed availability DTOs.
- Requires property identity, governed audience, section identity, and an explicit availability state.
- Supported states are EMPTY, MISSING, UNAVAILABLE, NOT_APPLICABLE, and WITHHELD.
- Optional source status and diagnostic codes are operational context, not consumer facts.

## Behavior

- EMPTY means there is no governed information to display; it does not mean the property lacks a feature.
- MISSING means the information is not currently available as a verified report fact.
- UNAVAILABLE means the governed source is currently unavailable; the UI does not infer why.
- NOT_APPLICABLE is distinct from missing or unavailable.
- WITHHELD communicates only that the information is not shown in the current report view.
- Seller/Public never receive source status or diagnostic codes.
- Agent may receive governed source status and diagnostic codes.
- No absence state may be translated into a negative property conclusion.
- Output is deterministic and fingerprinted.
