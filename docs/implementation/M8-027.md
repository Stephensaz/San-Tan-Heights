# M8-027 — Consumer Glossary UI

Status: IN_PROGRESS

## Purpose

Project the existing governed glossary into deterministic Agent, Seller, and Public consumer panels without creating a second glossary source or rewriting approved definitions.

## Behavior

- Uses the accepted `GlossaryResolver` as the only definition source.
- Resolves entries directly for the requested governed audience.
- Preserves source registry ID, glossary version, term ID, approved label, and approved definition.
- Includes universal terms and finding-related terms exactly as selected by the existing glossary resolver.
- Rejects duplicate term IDs and glossary version mismatches.
- Produces deterministic consumer glossary panel fingerprints.
- Does not author, expand, shorten, infer, or translate glossary definitions and does not change audience eligibility.
