# M4-011 — Render Deduplication

Status: ACCEPTED

Added render deduplication scoped to immutable report ID + render type + presentation input hash. Exact active presentation identity is reused; absent or failed/stale/invalidated/archived identity creates a new render path. Artifact bytes, timestamps, workers, and render version do not define dedup identity.

Acceptance evidence: reuse/create decisions, existing persistence query state exclusions, database uniqueness on report/render type/presentation hash, and full repository tests passed.
