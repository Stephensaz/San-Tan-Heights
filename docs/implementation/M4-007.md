# M4-007 — Render Request Service

Status: ACCEPTED

Added the governed bridge from immutable semantic reports to render production. The service resolves the render contract, binds approved media and diagrams, promotes TEMPLATE and BRANDING to first-class presentation dependencies, and calculates the exact presentation input hash. Presentation changes therefore regenerate render artifacts without changing semantic report identity. The request service does not render, publish, or invent content.

Acceptance evidence: template/branding dependency capture, media/diagram integration, presentation hash change sensitivity, render-contract enforcement, and full repository tests passed.
