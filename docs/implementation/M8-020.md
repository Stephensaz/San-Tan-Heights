# M8-020 — Agent PDF

Status: ACCEPTED

## Purpose

Compose the governed Agent report into a deterministic Agent PDF document model using the accepted M8-019 PDF template foundation, while preserving Agent-only evidence lineage and report meaning.

## Behavior

- Consumes only the accepted `AgentReportView`.
- Preserves property identity, freshness, summary, canonical section/card/finding order, disclaimers, and Agent-only lineage.
- Uses the locked M8-019 US Letter template plan for page geometry and flow rules.
- Retains `source_snapshot_id`, `semantic_fingerprint`, snapshot ID, and dependency-manifest hash for Agent use.
- Produces a deterministic Agent PDF document fingerprint.
- Does not consume Seller/Public views, downgrade or rewrite evidence, omit governed Agent content, or create PDF-specific property facts.
- Byte-level PDF rendering remains delegated to the certified renderer integration; this ticket establishes the Agent PDF composition contract so the older A4 adapter cannot silently override the locked Letter foundation.
