## Final rule

Certification is all-or-nothing.

- PASS / GO only when every required layer, stage gate, and acceptance criterion passes with zero open defects, zero waivers, zero source drift, and valid evidence.
- Otherwise FAIL / NO-GO.
- No conditional GO and no certification waivers.
- A failed result is repaired in the owning upstream M8 layer and the complete certification is rerun.
- There is no M8-033K.
