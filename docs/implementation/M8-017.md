# M8-017 — Responsive Layout System

Status: ACCEPTED

## Purpose

Provide a deterministic responsive layout contract that changes presentation geometry without changing semantic order, audience eligibility, or property meaning.

## Behavior

- Uses locked COMPACT, STANDARD, and WIDE viewport ranges.
- Preserves the exact semantic component order at every viewport size.
- Changes only card/media column counts, gutters, and content width.
- Uses the accepted M8-002 design token registry for gutter and maximum-content-width values.
- Rejects viewport widths outside the certified range, duplicate semantic identifiers, and unknown design-token references.
- Produces a deterministic responsive layout fingerprint.
- Does not hide governed content, reclassify audiences, reorder meaning, or create viewport-specific facts.
