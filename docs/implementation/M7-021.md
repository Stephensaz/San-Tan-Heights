# M7-021 — Progressive Automation Policy

Accepted in 0.1.46.

Automation requires an explicit, immutable handoff for a named rollout stage. The handoff is bound to the production-certification run, candidate fingerprint, immediate prior stage, exact prior PASS certification fingerprint, fresh CLEAR stop-condition evidence, requester identity, and reason code. Automation cannot bypass publication guards, mutate frozen membership, or auto-advance after a failed stage.
