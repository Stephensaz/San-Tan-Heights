# M8-023 — Print Templates

Status: ACCEPTED

## Purpose

Bind each already-governed Agent, Seller, and Public PDF document to a locked audience-specific print template without altering report facts, publication tier, or semantic order.

## Behavior

- Accepts only certified `AgentPdfDocument`, `SellerPdfDocument`, or `PublicPdfDocument` inputs.
- Infers the print audience from the certified document type instead of trusting caller-supplied audience labels.
- Uses locked US Letter geometry aligned to the accepted M8-019 PDF foundation.
- Preserves the exact certified PDF semantic section order.
- Forbids print-only content omission, audience reclassification, and print-specific fact changes.
- Requires repeated headers/footers, section-heading continuity, and card split avoidance according to the locked print contract.
- Produces a deterministic print-plan fingerprint bound to the exact source PDF document fingerprint.
- Does not render bytes, rewrite wording, infer facts, alter evidence, or broaden publication eligibility.
