# M6-008 Response DTO Segregation

PublicReportResponse, SellerReportResponse, and AgentReportResponse are physically distinct immutable response types built by whitelist projection from canonical report payloads. Public omits lineage/evidence internals; Seller adds seller-safe freshness/evidence fields without snapshot/fingerprint lineage; Agent retains governed report lineage. Projection validates the canonical report variant before constructing a response.
