# M7-008 — Shadow Cycle Tracking

Status: ACCEPTED

Implemented durable, immutable tracking for production shadow cycles and per-property/variant target results.

Key controls:
- cycle number is explicit and unique within a production certification run;
- exact frozen pilot membership fingerprint is retained;
- orchestrator evidence hash is preserved;
- target results are canonically ordered and independently evidence-hashed;
- PASS/FAIL target counts reconcile exactly to the cycle target count;
- persisted shadow-cycle evidence is append-only and immutable;
- no publication activation semantics are introduced by this ticket.
