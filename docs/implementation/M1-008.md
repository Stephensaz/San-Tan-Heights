# M1-008 — Processed Command Ledger

Status: ACCEPTED

Implements the command idempotency ledger in `audit.processed_commands`, keyed by `(service_name, idempotency_key)` and guarded by the canonical request hash. Reuse of an idempotency key with the same request returns the prior result; reuse with a different request raises `IDEMPOTENCY_KEY_PAYLOAD_MISMATCH`.

The ledger is intended to be written in the same transaction as the governed command's effects.
