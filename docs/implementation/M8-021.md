# M8-021 — Seller PDF

Status: IN_PROGRESS

## Purpose

Compose the governed Seller report into a deterministic Seller PDF document model using the accepted M8-019 PDF foundation without exposing Agent-only lineage.

## Behavior

- Consumes only the accepted `SellerReportView`.
- Preserves Seller-approved property identity, freshness, summary, canonical section/card/finding order, confidence wording, limitations, and disclaimers.
- Uses the locked M8-019 US Letter template plan.
- Omits Agent-only source snapshot IDs, semantic fingerprints, report snapshot ID, and dependency-manifest hash by construction.
- Produces a deterministic Seller PDF document fingerprint.
- Does not recover hidden lineage, broaden publication scope, rewrite evidence, or create PDF-specific property facts.
