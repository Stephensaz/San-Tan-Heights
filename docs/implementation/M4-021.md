# M4-021 — Atomic Publication Service

Status: ACCEPTED

Added transaction-scoped publication serialization and atomic semantic/channel pointer advancement after guard and freshness checks. The service appends publication history in the same caller transaction and performs no commit internally. Guard/freshness failures never touch current pointers; database failure propagates for caller rollback so the prior publication remains current.

Contract references: STH-PERSISTENCE-v1.0, STH-SERVICE-CONTRACT-v1.0.

Acceptance evidence: atomic publish success/failure tests plus full repository suite passed.
