# M4-013 — Render Artifact Immutability

Status: ACCEPTED

READY render artifacts are immutable presentation evidence. Report linkage, render type/version, render contract, template/renderer versions, presentation input hash, artifact hash/size, storage URI, MIME type, and render dependency rows cannot be rewritten once READY. Lifecycle control fields remain available for later stale/invalidation handling without rewriting artifact history.

Acceptance evidence: database trigger/constraint tests plus full repository certification passed.
