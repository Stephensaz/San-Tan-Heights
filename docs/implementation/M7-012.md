# M7-012 — Go-Live Stop Condition Engine

Status: ACCEPTED

Implemented an explicit stop-condition gate for production activation.

Key controls:
- evaluates every locked blocker rather than short-circuiting;
- stops on environment/configuration/shadow failures, nonzero hard-zero metrics, critical incidents, global publication freeze, candidate revocation, or candidate fingerprint drift;
- unknown configured conditions fail closed;
- produces deterministic immutable stop evidence.
