# M13-002 — Temporal Change Detection & Community Delta Engine

Status: IN_PROGRESS

## Purpose

Consume exactly two comparison-eligible, certified M13-001 community-state snapshots and produce an immutable, reproducible factual delta describing what changed between them.

M13-002 answers **what changed**. It does not decide how the platform should respond to that change.

## Frozen implementation boundary

M13-002 owns:

- exact before/after certified snapshot binding;
- deterministic field-level before/after comparison;
- explicit change classifications;
- exact temporal semantics for first observed, effective, recorded and detected time;
- UNKNOWN effective time when no governed effective time exists;
- explicit change-cause and causation-basis fields;
- UNKNOWN cause when support is insufficient;
- versioned materiality rules;
- exact evidence and snapshot lineage;
- immutable change fingerprints;
- descriptive impact edges identifying potentially stale derived objects;
- deterministic replay;
- explicit delta certification.

Supported change classifications are:

- `UNCHANGED`;
- `ADDED`;
- `REMOVED`;
- `MODIFIED`;
- `BECAME_KNOWN`;
- `BECAME_UNKNOWN`;
- `CONFLICT_INTRODUCED`;
- `CONFLICT_RESOLVED`;
- `SUPPRESSED`;
- `REACTIVATED`;
- `NOT_COMPARABLE`.

Supported change causes are:

- `REAL_WORLD_CHANGE`;
- `NEWLY_OBSERVED_FACT`;
- `SOURCE_CORRECTION`;
- `PLATFORM_CORRECTION`;
- `CLASSIFICATION_CHANGE`;
- `ENGINE_CHANGE`;
- `UNKNOWN`.

Causation basis remains separately recorded as `DATA_DRIVEN`, `RULE_DRIVEN`, `ENGINE_DRIVEN`, `MIXED`, or `UNKNOWN_CAUSE`.

## M13-003 boundary

An M13-002 impact edge may state that a governed downstream object is **potentially stale**.

It may not:

- invalidate that object;
- create a refresh job;
- recalculate intelligence;
- enqueue work;
- selectively refresh state;
- execute any downstream mutation.

Those responsibilities belong to M13-003.

## Hard prohibitions

M13-002 does not:

- compare uncertified or non-eligible snapshots;
- substitute live/current state for either snapshot;
- infer unsupported causation;
- infer unknown effective dates;
- reconcile upstream conflicts;
- mutate either source snapshot;
- mutate a certified delta;
- recalculate downstream intelligence;
- create seller recommendations;
- create listing actions;
- publish externally;
- mutate M12 execution state;
- propagate protected fields.

## Acceptance boundary

M13-002 may be accepted only when certified-snapshot eligibility, chronological comparison, all frozen change classes, temporal semantics, cause handling, materiality, lineage, potentially-stale edges, deterministic replay, and the hard M13-003 separation have executable passing tests with zero waivers and zero open blocking defects.
