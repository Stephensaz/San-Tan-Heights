# M13-007F — Conflict, Freshness, Unknown & Limitation Framework

Status: ACCEPTED

## Purpose

Consume the certified current D seller-intelligence state and its exact E change ledger, then govern downstream usability for every intelligence dimension.

## Usability states

F emits exactly:

- USABLE
- USABLE_WITH_LIMITATION
- REVIEW_REQUIRED
- BLOCKED
- UNKNOWN

## Governing behavior

Unresolved evidence conflicts block only the affected dimension. Stale intelligence is never silently promoted and requires review. Explicit unknowns remain unknown. Limitations remain attached to usable intelligence. Unaffected certified dimensions remain usable even when another dimension is blocked.

State-level stale dependencies remain visible and elevate the overall framework to REVIEW_REQUIRED without automatically corrupting unrelated dimensions.

## Boundary

F does not assemble the final seller decision brief, recommend a strategy, generate an action, predict an outcome, rank alternatives, score sellers, apply hidden weighting, execute M12 work, silently resolve conflicts, silently promote stale evidence, or infer unknown values.

## Acceptance

F passes only if D/E lineage matches exactly, every current dimension receives one deterministic usability assessment, conflict/stale/unknown/limitation handling is explicit, affected-dimension blocking is localized, unaffected intelligence remains available, replay is exact, inherited regressions pass, and zero waivers/open defects remain.
