# M8-006 — Audience Presentation Policy

Status: IN_PROGRESS

## Purpose

Enforce Agent, Seller, and Public presentation depth and eligibility by consuming the already-governed M3 report-variant policies.

## Guardrails

- Uses `registries/report-variants/{agent,seller,public}.yaml` as the source of truth.
- Presentation cannot broaden data classification or publication scope.
- Agent may see PUBLIC_DATA, SELLER_DATA, and AGENT_INTERNAL according to upstream scope.
- Seller may see PUBLIC_DATA and SELLER_DATA only.
- Public may see PUBLIC_DATA only.
- Evidence depth must monotonically decrease Agent → Seller → Public.
- Confidence visibility must monotonically decrease Agent → Seller → Public.
- The runtime fails closed when policy hierarchy or variant identity is invalid.
- This layer does not rewrite findings, confidence, evidence, eligibility, or policy classifications.
