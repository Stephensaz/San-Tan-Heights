# M13-006D — Pricing-Position & Listing-Timing Scenario Engine

Status: IMPLEMENTED / CERTIFICATION PENDING

## Purpose

Take an accepted M13-006B certified scenario context plus accepted M13-006C historical evidence and calculate only explicit, descriptive pricing-position and listing-timing differences from human-supplied assumptions.

Price output is limited to candidate price, certified reference price, absolute difference, percentage difference, and neutral direction. Timing output is limited to candidate date, certified reference date, day difference, and neutral direction.

## Hard prohibitions

M13-006D does not select or recommend a list price, recommend listing timing, predict sale price, sale probability, days on market, or any future outcome; infer causality; rank scenarios; select winners; compute hidden scores; execute M12 work; or publish externally.

## Acceptance

Acceptance requires exact B/C lineage, explicit assumptions, certified reference facts, deterministic price/date calculations, evidence and applicable-pattern context preservation, uncertainty/limitation carry-forward, deterministic replay, full inherited regressions, zero waivers, and zero open defects.
