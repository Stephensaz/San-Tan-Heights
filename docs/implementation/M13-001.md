# M13-001 — Community State Snapshot & Temporal Baseline

Status: ACCEPTED

## Purpose

Materialize an immutable, reproducible, timestamped, source-linked, versioned and hash-verifiable San Tan Heights community-state snapshot from the exact released Milestone 12 baseline.

M13-001 creates the temporal baseline only. It does not detect change or determine downstream impact.

## Accepted implementation

M13-001 now provides:

- explicit `observation_time`;
- explicit bitemporal `knowledge_cutoff`;
- `materialized_at` as record metadata rather than semantic state;
- exact released-M12 certification-root lineage;
- source, policy and runtime manifests;
- corpus/property projections using governed fingerprints rather than raw protected fields;
- freshness, exclusions and unresolved conflicts;
- deterministic semantic and record hashes;
- baseline linkage;
- replay validation;
- certification state;
- comparison eligibility gating.

## Hard prohibitions preserved

M13-001 does not:

- detect deltas or changes;
- propagate impact or selectively refresh intelligence;
- rewrite upstream identity or phase truth;
- rewrite historical state;
- infer missing dates or values;
- silently substitute newer/current data into an as-of snapshot;
- create seller recommendations;
- create listing actions;
- publish externally;
- mutate Milestone 12 execution state;
- propagate protected fields;
- accept source/policy/runtime drift silently.

Only a reproducible `CERTIFIED` snapshot with eligible freshness and no blocking condition may be comparison-eligible for M13-002.
