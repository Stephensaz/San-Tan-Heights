# M11-006 — Seller Intelligence Workspace & Case Management

Status: IN_PROGRESS

## Purpose

Assemble certified M11-001→005 seller intelligence, monitoring events, communication projections, evidence limitations, review state, and human decisions into a governed property-level workspace without creating a new intelligence, valuation, pricing, publication, or execution engine.

## Frozen boundary

M11-006 may:

- create one governed seller-intelligence case per property;
- register current certified opportunity, strategy, scenario, timeline, and communication artifacts;
- surface open human-review-required monitoring events;
- track acknowledged, pending, resolved, or superseded review items;
- preserve exact lineage to every M11-001→005 artifact;
- show limitations, stale/missing evidence, and unresolved review requirements;
- distinguish machine-generated intelligence from recorded human decisions;
- produce the next safe human-review step.

M11-006 does not:

- generate new market intelligence;
- determine value or recommend a list price;
- predict a sale price or guaranteed proceeds;
- infer seller motivation, acceptance, buyer behavior, or protected-class information;
- convert review state into automatic strategy changes;
- approve, publish, schedule, queue, transmit, or execute external actions;
- expose private seller strategy publicly.

## Acceptance boundary

M11-006 may be accepted only when case state is deterministic, artifact lineage is complete, human decisions are separately recorded from machine intelligence, unresolved review items cannot be silently cleared, stale/superseded artifacts remain visible, public leakage is prevented, prohibited price/value/outcome fields cannot be generated, external action capability remains NONE, and inherited certification gates pass.
