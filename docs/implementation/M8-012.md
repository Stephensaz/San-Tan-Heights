# M8-012 — Diagram Accessibility Layer

Status: IN_PROGRESS

## Purpose

Provide an accessible, deterministic nonvisual equivalent for every governed schematic diagram without creating new property facts or spatial claims.

## Behavior

- Generates concise accessible names and longer descriptions from the certified renderer output.
- Uses semantic reading order: subject first, then front, rear, side, and neutral context relationships.
- Produces a nonvisual text equivalent containing the same governed relationships as the diagram.
- Decorates certified SVG with deterministic `<title>` and `<desc>` elements plus `aria-labelledby`.
- Preserves source finding IDs internally for traceability but never exposes them in consumer descriptions or SVG.
- Always carries the schematic/not-a-map/not-to-scale limitation.
- Does not infer compass direction, distance, coordinates, value, desirability, or missing relationships.
