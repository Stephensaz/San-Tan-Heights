- immutable corpus manifest;
- deterministic corpus-manifest fingerprint;
- exact source snapshot references;
- canonical property identifier for every corpus member;
- admission-state enum;
- quarantine-reason enum;
- exclusion-reason enum;

- ADMITTED
- QUARANTINED
- EXCLUDED_WITH_GOVERNED_REASON

- no publication occurs in M9-001;
- no report generation occurs in M9-001;
- no new intelligence is derived in M9-001.
