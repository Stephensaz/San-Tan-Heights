# M8-019 — PDF Template Foundation

Status: ACCEPTED

## Purpose

Define the deterministic, audience-neutral PDF page and flow contract that later Agent, Seller, and Public PDF renderers will consume without changing governed report meaning.

## Behavior

- Uses locked US Letter geometry with deterministic margins and header/footer zones.
- Preserves the exact semantic section order supplied by the governed report layout.
- Repeats header and footer consistently across pages.
- Keeps a section heading with its first content block while allowing longer section bodies to split across pages.
- Rejects blank or duplicate semantic identifiers.
- Produces deterministic template and plan fingerprints.
- Does not omit content, reclassify audiences, create PDF-specific facts, or alter property meaning.
