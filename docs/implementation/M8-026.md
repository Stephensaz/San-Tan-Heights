# M8-026 — Branding Runtime

Status: ACCEPTED

## Purpose

Bind the locked San Tan Heights brand identity to the already-accepted locked presentation design tokens so Agent, Seller, and Public surfaces use one deterministic visual system without changing property intelligence or audience eligibility.

## Behavior

- Loads a locked branding registry and the existing locked `STH-DESIGN-TOKENS-v1.0` registry.
- Uses the existing white/black/silver/gold color tokens, spacing, radius, typography, and layout tokens without caller overrides.
- Produces deterministic branding plans for Agent, Seller, and Public across Web, PDF, and Print channels.
- Keeps brand identity and visual tokens constant across audiences while binding the plan to the requested governed audience/channel.
- Forbids runtime color or typography overrides.
- Does not change property facts, audience eligibility, disclosure visibility, wording, evidence, or routing.
