# M12-005 — Listing Action Policy Calibration & Controlled Promotion Framework

Status: ACCEPTED

## Purpose

Take certified M12-004 advisory operational-improvement candidates and convert them into isolated candidate versions of listing-action and execution policy that can be replayed, compared, approved, promoted, rejected, and rolled back without mutating the accepted M12-001→004 baseline in place.

## Accepted calibration framework

M12-005 now:

- creates immutable accepted execution-policy baselines;
- creates isolated candidate versions bound to exact parent version and parent fingerprint;
- accepts only eligible M12-004 advisory improvement candidates;
- replays current and candidate policies side-effect-free over governed fixtures;
- makes every changed policy field explicit;
- detects protected-control regressions;
- blocks promotion on any safety regression;
- requires separate human promotion approval;
- preserves exact rollback to the accepted baseline;
- produces only controlled `READY_FOR_M12_CERTIFICATION` promotion packages.

## Protected controls

A candidate fails closed if it weakens any governed control, including:

- human approval;
- independent authority;
- authority revalidation;
- deterministic idempotency;
- duplicate-side-effect suppression;
- no silent retry of outcome-unknown;
- independent verification;
- mismatch reconciliation;
- outcome-unknown reconciliation;
- separate rollback approval;
- separate rollback authority;
- rollback authority revalidation;
- immutable execution/verification/rollback receipts;
- seller-approval inference prohibition;
- system-determined price/terms prohibition;
- public-strategy exposure prohibition.

## Promotion boundary

No candidate promotes automatically.

A promotion package requires:

- zero safety regressions;
- explicit human approval;
- exact candidate fingerprint binding;
- exact baseline/rollback lineage.

The package remains non-public and has `external_action_capability: NONE`.
