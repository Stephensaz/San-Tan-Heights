# M1-009 — Transactional Outbox

Status: ACCEPTED

Implements the transactional outbox in `audit.event_outbox` and the consumer idempotency ledger in `audit.event_consumptions`.

Delivery semantics are explicitly **at least once**. Workers claim rows with `FOR UPDATE SKIP LOCKED`, use leases, retry safely, move exhausted deliveries to `DEAD_LETTER`, and rely on downstream consumer idempotency to prevent duplicate logical effects.

Outbox writes use the caller's database transaction; no separate commit is performed by the writer.
