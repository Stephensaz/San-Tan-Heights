# M12-001 — Listing Action Planning & Governed Action Proposal Engine

Status: IN_PROGRESS

## Purpose

Consume the released Milestone 11 Seller Intelligence case plus current listing context and explicit action intent, then produce an immutable governed listing-action proposal.

M12-001 is a proposal layer only.

It does not approve, authorize, schedule, queue, execute, publish, transmit, promote policy, or determine a seller decision.

## Frozen implementation boundary

Inputs:

- certified M11 Seller Intelligence case;
- exact released M11 certification root;
- released-M11 evidence fingerprint;
- current listing context;
- explicit action intent;
- current frozen action-proposal policy;
- optional recorded Agent judgment for AGENT_REQUEST origin.

Outputs:

- immutable proposal;
- exact source lineage;
- current policy version/fingerprint;
- prerequisites;
- limitations;
- explicit proposal/approval/authorization/schedule/queue/execution/publication/transmission states.

## Authority separation

Every proposal must remain:

- `proposal_status: PROPOSED`;
- `approval_state: NOT_APPROVED`;
- `authorization_state: NOT_AUTHORIZED`;
- `schedule_state: NOT_SCHEDULED`;
- `queue_state: NOT_QUEUED`;
- `execution_state: NOT_EXECUTABLE`;
- `publication_state: NOT_PUBLISHED`;
- `transmission_state: NOT_TRANSMITTED`;
- `requires_human_approval: true`;
- `public_eligible: false`;
- `external_action_capability: NONE`.

M12-002, not M12-001, owns any later authorization/execution boundary.
