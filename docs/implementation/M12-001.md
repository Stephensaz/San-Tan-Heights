# M12-001 — Listing Action Planning & Governed Action Proposal Engine

Status: ACCEPTED

## Purpose

Consume the released Milestone 11 Seller Intelligence case plus current listing context and explicit action intent, then produce an immutable governed listing-action proposal.

M12-001 is a proposal layer only.

It does not approve, authorize, schedule, queue, execute, publish, transmit, promote policy, or determine a seller decision.

## Accepted implementation

M12-001 now requires:

- released certified M11 baseline;
- exact M11 release certification root;
- released-M11 evidence fingerprint;
- current listing context;
- explicit action intent;
- current frozen action-proposal policy;
- current review item for `SYSTEM_SIGNAL`;
- separately recorded Agent judgment for `AGENT_REQUEST`.

The proposal preserves exact lineage to the M11 case, M11 release proof, listing context, source context, action intent, policy, review event/review item where applicable, and Agent judgment where applicable.

## Authority separation

Every proposal remains:

- `proposal_status: PROPOSED`;
- `approval_state: NOT_APPROVED`;
- `authorization_state: NOT_AUTHORIZED`;
- `schedule_state: NOT_SCHEDULED`;
- `queue_state: NOT_QUEUED`;
- `execution_state: NOT_EXECUTABLE`;
- `publication_state: NOT_PUBLISHED`;
- `transmission_state: NOT_TRANSMITTED`;
- `requires_human_approval: true`;
- `public_eligible: false`;
- `external_action_capability: NONE`.

## Fail-closed controls

M12-001 rejects:

- stale listing context;
- stale policy version;
- wrong M11 release root;
- uncertified M11 baseline;
- mismatched property lineage;
- resolved or superseded review targets;
- unsupported action types;
- public-eligible or externally actionable Seller Intelligence cases.

The proposal DTO contains no price, terms, seller-message payload, approval ID, authorization ID, schedule, queue, execution receipt, publication action, transmission action, or external-action field.
