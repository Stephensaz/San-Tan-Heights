# M7-010 — Manual Audit Evidence Capture

Status: ACCEPTED

Implemented append-only manual-audit evidence capture for properties in the frozen audit sample.

Key controls:
- evidence may be captured only for a sampled property;
- audit status is limited to PASS, FAIL, or REVIEW_REQUIRED by the locked policy;
- checklist version and checklist results are retained with a canonical evidence hash;
- reviewer identity and optional notes are persisted;
- evidence rows are immutable once written;
- this layer records human audit facts only and deliberately does not compute a go-live verdict.
