# M13-007A — Unified Intelligence Schema, Source Taxonomy & Governance

Status: IMPLEMENTED — AWAITING ACCEPTANCE

## Purpose

Define the immutable property-level seller-intelligence state, source taxonomy, evidence-lineage requirements, freshness states, conflict states, change states, significance classes, and hard decision/execution boundaries for M13-007.

## Boundary

M13-007A defines governance and schemas only. It does not bind cross-system evidence, determine property applicability, synthesize a live seller state, compute prior-state deltas, resolve conflicts, assemble seller briefs, recommend actions, or execute listing activity.

## Source taxonomy

The only governed source classes are:

- CERTIFIED_FACT
- CURRENT_OBSERVATION
- HISTORICAL_OBSERVATION
- PROMOTED_PATTERN
- EXPLICIT_SCENARIO_ASSUMPTION
- SCENARIO_RESULT
- UNKNOWN
- LIMITATION
- HUMAN_INPUT

These classes remain distinct through downstream synthesis.

## Hard prohibitions

M13-007A cannot select price or strategy, recommend whether/when to list, rank/select scenarios, predict price/DOM/probability/appreciation, infer seller motivation or urgency, score leads/opportunity, generate/approve/execute M12 actions, contact homeowners, publish externally, mutate upstream intelligence, silently refresh stale inputs, or infer unknown values.

## Acceptance

A passes only if the schema and taxonomy are deterministic, material items require evidence lineage, unknowns remain unknown, stale/conflict states are explicit, significance classifications describe evidence change only, decision/execution fields are absent, inherited regressions pass, and zero waivers/open defects remain.
