# M10-005 — Community Portability Pilot & Measured Rebuild Proof

Status: IN_PROGRESS

## Purpose

Use the accepted M10-003 onboarding contract and M10-004 progressive pipeline to execute a measured second-community portability pilot and prove how much of the San Tan Heights platform can be reused without copying hidden community assumptions.

## Frozen boundary

M10-005 owns pilot selection criteria, synthetic-or-approved pilot input preparation, measured reuse/remediation accounting, stage-by-stage execution through the M10-004 pipeline, portability metrics, exception capture, and rebuild-effort evidence.

M10-005 does not declare the platform reusable for all communities, does not perform third-community cold-start validation, does not publish the pilot community, does not weaken a failed M10-004 stage, and does not mutate San Tan Heights Production Baseline v1.0.0.

## Required proof

- select one governed second-community pilot that is materially distinct enough to expose hidden assumptions;
- generate an M10-003-compliant onboarding bootstrap;
- traverse the full M10-004 pipeline;
- measure reusable versus community-configurable versus community-specific versus source-specific work;
- measure manual remediation required;
- record all portability exceptions and owning components;
- preserve exact parent-platform lineage;
- produce deterministic pilot and rebuild fingerprints;
- quantify rebuild effort using observable engineering artifacts rather than estimates alone.

## Acceptance boundary

M10-005 may be accepted only when the pilot completes the full progressive pipeline, all remediation is explicitly classified, reuse/remediation metrics are reproducible, no hidden San Tan Heights assumptions remain unaccounted for, accepted baseline artifacts remain unchanged, and inherited regression/certification gates pass.
