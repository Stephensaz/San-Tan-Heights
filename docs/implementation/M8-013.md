# M8-013 — Media Pipeline

Status: IN_PROGRESS

## Purpose

Provide a deterministic, governance-first presentation media manifest without turning the presentation layer into a media store or a new source of property intelligence.

## Behavior

- Registers immutable media descriptors by content SHA-256.
- Requires provenance reference and accessibility text for every asset.
- Validates media kind and MIME type against a locked policy registry.
- Carries explicit Agent/Seller/Public and Web/PDF/Print eligibility scopes.
- Produces deterministic, policy-bound media manifests.
- Eligibility filtering can only narrow scope; it cannot broaden publication eligibility.
- Does not fetch remote content, transform media, infer property meaning, rank assets, or mutate source files.
