# M10-004 — New-Community Build Pipeline & Progressive Certification

Status: IN_PROGRESS

## Purpose

Consume an M10-003-approved onboarding bootstrap and execute a governed, stage-gated new-community build pipeline that proves identity, source, ingestion, evidence, report, presentation, and release-readiness boundaries progressively without allowing later stages to conceal an earlier failure.

## Frozen boundary

M10-004 owns pipeline stage orchestration, prerequisite enforcement, stage evidence manifests, deterministic candidate fingerprints, progressive certification status, fail-closed stop behavior, and explicit handoff into later portability proof.

M10-004 does not select a permanent second-community pilot, change property-intelligence semantics, publish a community, mutate San Tan Heights Production Baseline v1.0.0, or waive a failed prerequisite.

## Required stages

1. onboarding/bootstrap validation;
2. identity and jurisdiction binding;
3. source/adaptor readiness;
4. corpus admission readiness;
5. evidence/passport readiness;
6. report-materialization readiness;
7. presentation/integrity readiness;
8. candidate freeze and progressive certification summary.

Each stage must require successful predecessor evidence, produce deterministic evidence/fingerprints, and stop the pipeline on failure.

## Acceptance boundary

M10-004 may be accepted only when a synthetic new-community fixture can traverse the complete pipeline deterministically, intentional failures at each stage stop downstream execution, no San Tan Heights-specific default is introduced, stage evidence is reproducible, accepted baselines remain unchanged, and inherited regression/certification gates pass.
