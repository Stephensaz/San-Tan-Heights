# M8-001 — Presentation Package Bootstrap

Status: IN_PROGRESS

## Purpose

Establish the consumer-presentation package boundary without implementing design tokens, UI components, diagrams, media, PDFs, or template certification.

## Locked inputs

The presentation layer consumes only governed report/render references and fingerprints. It must not create, infer, score, reword, or reinterpret property intelligence.

Supported audiences:

- AGENT
- SELLER
- PUBLIC

Supported channels:

- WEB
- PDF
- PRINT

## Bootstrap artifacts

- `src/presentation/__init__.py`
- `src/presentation/package.py`
- `schemas/presentation/presentation-package.schema.json`
- `tests/unit/presentation/test_presentation_package_bootstrap.py`

## Acceptance boundary

M8-001 is complete when the package boundary is immutable, validates governed hashes and locked presentation-contract identity, exposes deterministic target keys, and passes its unit tests. Design-token work belongs to M8-002.
