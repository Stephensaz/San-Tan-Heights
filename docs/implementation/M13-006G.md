# M13-006G — Multi-Scenario Comparison & Tradeoff Engine

Status: IMPLEMENTED / CERTIFICATION PENDING

## Purpose

Compare multiple accepted scenario states across the same governed dimensions while preserving the human-defined scenario order, exact lineage, coverage visibility, uncertainty, limitations, and pairwise differences.

## Hard prohibitions

M13-006G does not rank scenarios, choose a winner, recommend a scenario, apply weights, calculate an aggregate preference or utility score, reorder scenarios, predict outcomes, infer causality, execute M12 actions, or publish externally.

## Acceptance

Acceptance requires exact D/E/F lineage, unique human order, deterministic dimension materialization, deterministic pairwise comparison, descriptive coverage counts only, explicit uncertainty/limitations, deterministic replay, full inherited regressions, zero waivers, and zero open defects.
