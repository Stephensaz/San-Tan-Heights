# M1-011 — Transition Registry Runtime

Status: ACCEPTED

Implemented a typed transition registry, state-signature resolver, and caller authorization boundary. The runtime consumes only the already cross-reference-validated transition registry and fails closed for unknown transitions, illegal state paths, and unauthorized callers.

## Key files
- `src/kernel/transitions/transition_model.py`
- `src/kernel/transitions/transition_registry.py`
- `src/kernel/transitions/transition_resolver.py`
- `src/kernel/transitions/transition_authorization.py`
- `tests/unit/test_transition_registry_runtime.py`

## Acceptance
- Known transition resolves by ID and state signature.
- Unknown transitions fail closed.
- Unauthorized caller is rejected.
- Required guard/event references remain validated by the registry bundle loader.
