# M13-006B — Certified Baseline Assembly & Pattern Applicability Engine

Status: IMPLEMENTED / CERTIFICATION PENDING

## Purpose

Bind an accepted M13-006A READY scenario contract to the exact certified baseline it names, revalidate scenario facts and their source lineage, and determine which already-promoted M13-005 historical patterns are applicable to that governed context.

## Frozen behavior

Pattern applicability is always explicit: `APPLICABLE`, `NOT_APPLICABLE`, or `UNKNOWN`. Unknown or missing context is never treated as a match. Pattern statements, limitations, candidate fingerprints, and temporal-ledger lineage are preserved without reinterpretation.

## Hard prohibitions

M13-006B does not calculate scenario outcomes, predict a sale result, recommend a price or action, rank scenarios, select a winner, compute a hidden score, execute M12 work, publish externally, promote a new pattern, mutate a promoted pattern, or suppress uncertainty/limitations.

## Acceptance

Acceptance requires exact scenario/baseline identity and fingerprint binding, scenario-fact reconciliation, promoted-pattern-only enforcement, deterministic applicability, complete lineage and limitation carry-forward, deterministic replay, all inherited M13/M12 regressions green, zero waivers, and zero open defects.
