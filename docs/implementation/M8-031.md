# M8-031 — Visual Regression Harness

Status: ACCEPTED

## Purpose

Provide a deterministic visual verification layer for the frozen presentation system. The harness consumes certified fixtures and governed presentation outputs, captures controlled visual artifacts, compares them to certified baselines, runs structural assertions, classifies differences, and emits review evidence.

## Scope

- Agent, Seller, and Public web presentation targets.
- Desktop, tablet, mobile, and narrow-mobile controlled viewports.
- PDF and print presentation targets.
- Diagrams, media, evidence, limitations, glossary, What Changed, freshness, empty states, and branding surfaces.
- Controlled browser/runtime metadata, deterministic capture hashes, comparison records, structural assertions, and diff classification.

## Controlled runtime

- Chromium / Ubuntu 24.04.
- Device pixel ratio 1.
- Locale en-US.
- Timezone America/Phoenix.
- Frozen clock.
- Animations disabled.
- Locked viewports: 1440x1000, 1280x900, 834x1112, 390x844, 320x800.

## Structural hard failures

The harness must fail closed for hard visual defects including missing limitation text, cropped text, wrong-audience content, missing freshness, and meaning-changing diagram misalignment.

## Diff classes

- EXPECTED
- REVIEW_REQUIRED
- UNEXPECTED

## Non-goals

- Does not decide semantic correctness.
- Does not determine publication eligibility or audience authorization.
- Does not decide evidence sufficiency.
- Does not generate or modify property intelligence.
- Does not create the M8-032 golden presentation fixture set.
