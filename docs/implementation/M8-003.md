# M8-003 — Shared Component Primitives

Status: IN_PROGRESS

## Purpose

Define reusable, audience-neutral presentation primitives that can compose governed report content without introducing new intelligence.

## Primitives

- TEXT
- STACK
- CARD
- DIVIDER
- DISCLOSURE

## Guardrails

- Components are immutable and fingerprintable.
- Component IDs are stable lowercase slugs.
- Approved text must be nonempty.
- Semantic override properties such as scores, rankings, valuation, premium, desirability, audience overrides, publication overrides, and confidence overrides are rejected.
- Audience behavior belongs to M8-006.
- Property meaning remains upstream in governed report content.
