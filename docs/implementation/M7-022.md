# M7-022 — Rollback Baseline Capture

Accepted in 0.1.46.

Before progressive automation begins, the system captures immutable semantic-current and channel-render pointer state for every target property/variant/channel in the stage. Baselines are deterministic, bound to the automation handoff and candidate, require complete target-property coverage, and become the authoritative input for M7-023 rollback/containment rather than reconstructing pre-change state after failure.
