# M13-009 — Continuous Intelligence Certification

Status: ACCEPTED

## Purpose

M13-009 makes certification an explicit output of every governed intelligence refresh. It does not create a new analytics engine. It evaluates whether the required certified artifacts for the current property and temporal boundary remain usable as a complete governed set.

## Required certification inputs

Each cycle requires certified representations of the community snapshot, temporal delta, temporal history, promoted patterns, scenario intelligence, unified seller intelligence, and historical replay controls.

Each artifact carries an exact artifact fingerprint, lineage fingerprint, explicit state, and reason when not certified.

## Certification outcomes

- CERTIFIED — all required artifacts are present and certified, with no detected drift.
- REVIEW_REQUIRED — required artifacts are present but one or more are degraded or stale, or drift has been detected.
- BLOCKED — a required artifact is missing or explicitly blocked.

Prior certification receipts are immutable and may be linked only by fingerprint.

## Boundary

M13-009 performs certification only. It does not repair evidence, silently recertify stale material, suppress conflicts, make recommendations, predict outcomes, rank alternatives, score sellers, contact homeowners, market properties, set prices, execute actions, or bypass M12 controls.

## Acceptance

M13-009 passes only if certification is deterministic, every required artifact is accounted for, stale/degraded/drift states cannot silently certify, missing/blocked evidence fails closed, prior receipts remain immutable, inherited M13 and M12 regressions remain green, and zero waivers/open defects remain.
