# M13-006H — Uncertainty, Limitation & Scenario Explainability Framework

Status: IMPLEMENTED / CERTIFICATION PENDING

## Purpose

Produce deterministic, traceable explanations of certified facts, explicit assumptions, modeled dimensions, changes from reference, evidence lineage, promoted-pattern context, unknowns, limitations, and pairwise scenario differences.

## Hard prohibitions

M13-006H does not turn historical associations into predictions, assumptions into facts, uncertainty into confidence, or descriptive differences into recommendations. It does not rank scenarios, choose winners, invent causality or confidence, compute hidden scores, execute M12 actions, or publish externally.

## Acceptance

Acceptance requires exact A→G lineage, explicit fact/assumption separation, explicit changes, evidence fingerprints, pattern context, unknowns, limitations, preserved pairwise differences, deterministic replay, full inherited regressions, zero waivers, and zero open defects.
