# M4-005 — Media Slot Binding

Status: ACCEPTED

Added governed media-slot binding using the canonical report media slots and locked media policy. Subject-property media must match the report property, approval must be APPROVED, rights must be CLEARED, and the asset class must be compatible with the slot. Optional slots degrade to an explicit omission; required slots fail closed. Unrelated homes, stock homes represented as the subject, and different-lot substitutions are prohibited. Every bound asset emits an exact MEDIA presentation dependency with asset fingerprint, version, and slot lineage.

Acceptance evidence: property isolation, approval/rights enforcement, safe optional omission, required-slot blocking, exact dependency capture, and full repository tests passed.
