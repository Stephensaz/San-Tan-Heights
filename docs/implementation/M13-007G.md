# M13-007G — Governed Seller Decision-Brief Assembly

Status: IMPLEMENTED — AWAITING ACCEPTANCE

## Purpose

Assemble the certified A→F seller-intelligence outputs into one deterministic human-review brief for the subject property.

## Included content

The brief carries forward the current seller-intelligence state, detected changes, significance classes, per-dimension usability, source fingerprints, unknowns, limitations, exclusions, review-required conditions, and blocked dimensions.

## Boundary

G is assembly only. It introduces no new analytics or judgment. It does not recommend a list price, select a pricing strategy, recommend whether or when to list, generate actions, predict outcomes, rank scenarios, score sellers, apply hidden weighting, mutate source artifacts, or execute M12 work.

## Acceptance

G passes only if current-state, change-ledger, and usability fingerprints align exactly; all dimensions are covered; blocked dimensions cannot appear as usable; unknowns, limitations, exclusions, review conditions, and evidence lineage remain explicit; replay is deterministic; inherited regressions pass; and zero waivers/open defects remain.
